# 🎮 ARENA – Gaming Tournament Portal

**Compete. Conquer. Repeat.**

ARENA is a web-based esports tournament management platform built with React and Vite. It allows gamers to explore tournaments, register for competitions, manage teams, track matches, view results, and compete for top positions on leaderboards.

## 🚀 Features

- **User Authentication** – Login and signup functionality.
- **Tournament Discovery** – Explore available gaming tournaments.
- **Tournament Registration** – Register for competitions.
- **Team Management** – Manage gaming teams.
- **Match Schedules** – View upcoming matches.
- **Results & Leaderboards** – Track tournament results and player rankings.
- **User Dashboard** – Manage personal activities and registrations.
- **Admin Dashboard** – Manage tournaments, users, matches, and results.
- **Responsive Design** – Works across desktop, tablet, and mobile devices.

## 💻 Installation & Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/klu2500031471/ARENA-Gaming-Tournament-Portal.git
```

**2. Navigate to the project directory**

```bash
cd ARENA-Gaming-Tournament-Portal
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open in your browser**

```text
http://localhost:5173
```

## 📦 Build for Production

To create an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 💾 Data Storage

ARENA uses browser LocalStorage to store application data such as user information, tournament registrations, teams, and match details.

**Note:** This project currently uses frontend-based storage and demo authentication. It does not use a centralized backend database. LocalStorage data is specific to each browser.
